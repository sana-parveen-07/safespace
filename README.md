# SafeSpace 🚨

SafeSpace is a web application designed to help users in emergency situations by sending instant alerts, sharing live location, and notifying emergency contacts.

## 🚀 Features

- One-tap emergency alert button
- Sends SMS alerts to emergency contacts using Twilio
- Sends email with live location details
- Fake call feature for emergency escape situations
- Simple and fast user interface for quick response

## 🛠️ Tech Stack

- Frontend: EJS, HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- APIs: Twilio (SMS), Email service
